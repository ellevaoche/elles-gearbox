# Changelog

Release notes are generated from Conventional Commits and published with each
version in [GitHub Releases](https://github.com/ellevaoche/elles-gearbox/releases).
That is the canonical version history; no release commits are written back to
the source branch.

The initial release provides:

- Elle's Gearbox branding and original toolbox/sprocket icon.
- A 36-extension Windows/WSL inventory, covered by 24 direct entries and nested packs.
- Inventory previews, explicit updates, and offline coverage validation.
- Tested VSIX packaging and automated GitHub releases.
